## Step 5: Create a branch and merge changes

Create a feature branch:

```
git checkout -b feature/add-project-info
```

Add a new feature file:

```
echo "Feature: project information" > src/project-info.txt
git add src/project-info.txt
git commit -m "Add project information feature"
git push -u origin feature/add-project-info
```

Merge the feature into the main branch:

```

git merge feature/add-project-info
git push origin main
```

This demonstrates branch creation, committing changes on a branch, merging, and pushing to GitHub.
